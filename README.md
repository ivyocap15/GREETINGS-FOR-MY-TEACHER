# 🌸 Teachers' Day Digital Greeting Card

A creative and personalized **Teachers' Day Digital Greeting Card** made using HTML, CSS, and JavaScript.

The card features a soft, girly, minimalist design inspired by an open book. It includes a personalized photo of **Mr. Randy Bello**, a heartfelt Teachers' Day message, floral decorations, and an interactive celebration animation.

## ✨ Features

- 📖 Open-book inspired digital greeting card
- 🌸 Girly pastel pink minimalist design
- 👨‍🏫 Personalized teacher photo
- 💌 Customized Teachers' Day message
- 💗 Hearts and floral decorations
- ✨ Interactive "Celebrate" button
- 🎉 Animated floating hearts and flowers
- 📱 Responsive design for desktop and mobile
- 💻 Built using only HTML, CSS, and JavaScript
- 🚫 No external frameworks required
